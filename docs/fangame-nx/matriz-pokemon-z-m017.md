# M017 · Matriz de prueba de Pokémon Z 2.18

La observación comunicada hasta ahora es que el juego «funciona» y «va de
puta madre» en la Nintendo Switch. Las comprobaciones siguientes no se
deducen de esa frase ni de la presencia de logs o `LastSave.dat`.

| Hito | Estado registrado | Qué comunicar tras probarlo |
|---|---|---|
| Arranque general del juego | Confirmado por el propietario | Pantalla alcanzada y tiempo aproximado, si se quiere precisar |
| Portada en la ficha FangameNX | Pendiente | Visible / placeholder / error; foto opcional |
| Controles del mando | Pendiente | Cruceta, A, B, X y menús que responden |
| Audio | Pendiente | Música y efectos audibles, o silencio/fallo |
| Entrada al primer mapa | Pendiente | Nombre o número del mapa alcanzado |
| Transición entre mapas | Pendiente | Origen, destino y si terminó sin bloqueo |
| Guardado de partida nueva | Pendiente | Confirmación dentro del juego y archivo creado; no usar una partida previa |
| Carga tras reiniciar | Pendiente | Si reaparece la partida nueva en el mismo punto |
| Retorno a FangameNX | Pendiente | Acción realizada y pantalla final; no asumir que B cierra este juego |
| Estabilidad | Pendiente | Duración aproximada y cualquier bloqueo o pánico |

Si falla una prueba, conservar `mkxp-boot.log`, `mkxp-debug.log`,
`mkxp-ruby.log`, `errorlog.txt` y `logs/launcher.log` antes de cambiar la
instalación. La tabla está preparada para recibir resultados del propietario;
no se ha ejecutado una nueva sesión de hardware durante M017.
